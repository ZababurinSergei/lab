JSON patch

Условие задачи

Реализуйте функцию jsonPatch, которая применяет набор трансформаций к JSON-объекту.

Функция принимает два параметра:

  • obj — произвольный JSON-объект (может содержать объекты, массивы, примитивные значения)
  • transformations — массив функций-трансформаций

Каждая функция-трансформация принимает два аргумента:

  1. path — массив строк и чисел, представляющий путь к текущему узлу в дереве объекта (строка для поля объекта, число для индекса массива)
  2. value — текущее значение узла

Трансформация может вернуть:

  • undefined — узел остается без изменений
  • null — узел удаляется из результата
  • любое другое значение — узел заменяется на это значение

Алгоритм работы

  1. Функция рекурсивно обходит все узлы дерева объекта.
  2. Для каждого узла применяются все трансформации в порядке их следования в массиве. Каждая трансформация получает один и тот же вход: текущее значение узла (уже обработанное рекурсивно для вложенных объектов и массивов). Результат предыдущей трансформации следующей не передаётся — трансформации не накопительные.
  3. Если несколько трансформаций возвращают не-undefined значения, используется результат последней из них (последняя «перекрывает» предыдущие, в том числе перекрыть может и null).
  4. После применения трансформаций, если результат является объектом или массивом, он также рекурсивно обрабатывается.
  5. Узлы, для которых итоговый результат трансформаций — null, удаляются из результата.
  6. Удаление элементов из массива: результирующий массив получается сжатием — удалённые элементы не оставляют «дыр»; индексы следующих элементов сдвигаются.

Формат функции

export function jsonPatch(obj, transformations) {
  // ваша реализация
}

Пример

Входные данные:

obj = {
  a: 1,
  b: 2,
};

transformations = [
  (path, value) => {
    if (typeof value === "number") {
      return value * 10; // умножить все числа на 10
    }
  },
  (path) => {
    if (path.length === 1 && path[0] === "b") {
      return null; // удалить 'b' (последняя трансформация — её результат применяется)
    }
  },
];

Результат:

{
  a: 10; // 'b' удалён, 'a' умножен на 10
}

Порядок трансформаций важен: если бы удаление b шло первым, а умножение вторым, то для b последним был бы результат второй трансформации (20), и поле b осталось бы в объекте.

Примечания

  • Путь к корневому объекту — пустой массив [].
  • Путь к полю объекта — массив с именем поля: ['fieldName'].
  • Путь к элементу массива — массив с индексом: ['arrayName', 0].
  • Путь к вложенному полю — массив с путём: ['parent', 'child'].
  • Если корневой объект удаляется (итоговый результат трансформаций — null), функция должна вернуть undefined.
  • Заменённые объекты и массивы также должны обрабатываться рекурсивно.
  • При удалении элементов массива (возврат null для элемента) массив сжимается: дыр в индексах нет.

Ограничения

  • Гарантируется, что исходный объект не содержит null или undefined как значения полей
  • Все трансформации корректны и не вызывают ошибок
  • Размер объекта не превышает разумных пределов для рекурсивной обработки
