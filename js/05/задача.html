Машина Голдберга на CSS

Вам досталась уже готовая страница с небольшой «машиной Голдберга». Вёрстка и базовые стили сцены полностью подготовлены — трогать HTML нельзя. Но сейчас механизм «не оживает»: нужно дописать только CSS, чтобы по запуску отрабатывала цепочка анимаций так, как показано в видео.

Вы не должны использовать JavaScript ни в каком виде. Управление запуском происходит через чекбокс #start и селекторы состояния (:checked), а дальше — через CSS-анимации и задержки.

Для разработки и тестирования скачайте шаблон и ориентируйтесь на видео-референс. В качестве решения принимается файл solution.css.

Примечание

Точные координаты и тайминги не выдаются — их нужно подобрать по видео, добившись максимально похожего поведения. До запуска шарик должен оставаться неподвижным, а решение должно быть устойчивым к повторному переключению состояния.
