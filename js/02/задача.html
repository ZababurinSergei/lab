Яблоневый сад

У Димы есть яблоневый сад, в котором яблони расположены в один длинный ряд. Каждая яблоня может приносить различное количество яблок.

Пора собирать урожай! Однако, сад получился таким красивым! Дима хочет собрать урожай таким образом, чтобы одновременно выполнялись два условия:

  1. С яблонь, стоящих рядом, нельзя собирать яблоки одновременно — Дима не собирает урожай с двух соседних деревьев, чтобы сад визуально остался красивым.

  2. Общее количество собранных яблок должно быть максимальным.

Дима должен понять, сколько максимум яблок он может собрать. Для этого он использует свой телефон и специальные гаджеты.

Анализ яблонь

На каждой яблоне установлен анализатор, который:

  • определяет количество яблок N[i] на дереве с индексом i;
  • выполняет измерение асинхронно, причём время анализа неизвестно.

После завершения анализа результат автоматически передаётся на телефон Димы.

Поведение телефона

У Димы есть старенький телефон, на который приходят результаты анализа.

  • Память телефона для сообщений об анализе ограничена.
  • Если память телефона заполнена, новый результат анализа не сохраняется.
  • Потерянный результат анализа считается недоступным и, при необходимости, анализ соответствующей яблони должен быть выполнен повторно.
  • Дима может в любой момент очистить память телефона, но это занимает какое-то время.
  • Пока идёт очистка памяти, телефон не может принимать новые сообщения и делать повторную очистку.
  • Так как телефон старый, очистка памяти иногда работает с перебоями, но Дима выявил закономерность: 
    Представим, что n — счётчик операций очистки. Счётчик увеличивается с каждой очисткой памяти.
Если n % 3 === 1, то удалится 1 сообщение.
Если n % 3 === 2, то удалятся 2 сообщения.
Если n % 3 === 0, то удалятся все 3 сообщения

Функция harvest

Функция, которую вам необходимо реализовать. Параметры:

  • treesCount — количество деревьев в саду. Деревья выстроены в один длинный ряд. У каждого дерева свой индекс, соответствующий его положению в ряду. Индекс первого дерева — 0.
  • phone — экземпляр Phone для получения результатов анализа

API и интерфейсы

Класс Phone

interface Phone extends EventEmitter {
  // Запускает очистку памяти телефона (асинхронно). Но подписаться на окончание события из этой функции нельзя
  clearMessages(): void

  // Событие "analyze" эмитится при завершении анализа дерева
  // treeIndex — индекс проанализированного дерева
  // applesCount - количество яблок на дереве
  on("analyze", (treeIndex, applesCount) => void): void

  // Событие "messagesCleared" эмитится после очистки памяти
  // memoryLeft - количество свободных ячеек для сообщений в памяти после очистки
  on("messagesCleared", (memoryLeft) => void): void

  // Максимальная память (только для чтения)
  readonly maxMemory: number
}

Функция analyzeTree

type AnalyzeTree = (treeIndex: number) => void;

Вызов analyzeTree(treeIndex) запускает асинхронный анализ яблони с индексом treeIndex. Но подписаться на окончание события из этой функции нельзя.

Важно: После завершения анализа, если память доступна, телефон эмитит событие «analyze» с параметрами (treeIndex, applesCount).

Если память заполнена в момент завершения анализа, результат теряется.
