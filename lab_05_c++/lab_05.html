📐 Блок-схема алгоритма (по ГОСТ 19.701-90)

Алгоритм вычисляет сумму бесконечного ряда S = Σ ln(1 - 4x²/((2k-1)²π²)) с заданной точностью ε.
Блок-схема выполнена в строгом соответствии с ГОСТ 19.701-90 (ISO 5807-85).

✅ Стрелки только при движении снизу вверх или справа налево
✅ Линии только вертикальные и горизонтальные
✅ Подписи «Да»/«Нет» рядом с линиями, не пересекая их
✅ Стрелка точно на конце линии, не смещена
✅ Пересечения линий — дуга (мостик) не нарушает линию
✅ Параллелограмм для ввода/вывода
Рисунок 1 — Блок-схема алгоритма суммирования ряда (вариант 9).
Выполнена по ГОСТ 19.701-90: линии непрерывны, стрелки на линиях снизу вверх и справа налево.

📖 Пояснения к блок-схеме

🔷 Последовательность работы алгоритма:
  • Ввод данных: x, точность ε, максимальное количество итераций.
  • Инициализация: S = 0, k = 1.
  • Вычисление аргумента логарифма: если arg ≤ 0 — ошибка, завершение.
  • Вычисление term = ln(arg) и накопление суммы S += term.
  • Вывод промежуточных значений (отладка).
  • Инкремент счётчика k = k + 1.
  • Проверка условия продолжения: если |term| ≥ ε и k ≤ max_iter — переход к следующей итерации, иначе — выход.
  • Вывод результата: итоговая сумма S и количество выполненных итераций.

🧾 Фрагмент программного кода

// Реализация циклического суммирования (вариант 9)
double x, S = 0.0, term, epsilon;
int k = 1, max_iter;

printf("Введите x: "); scanf("%lf", &x);
printf("Введите epsilon: "); scanf("%lf", &epsilon);
printf("Введите max_iter: "); scanf("%d", &max_iter);

do {
    double denominator = (2.0*k - 1)*(2.0*k - 1)*M_PI*M_PI;
    double arg = 1.0 - (4.0*x*x) / denominator;
    if (arg <= 0) {
        printf("Ошибка: аргумент логарифма ≤ 0 при k = %d\n", k);
        break;
    }
    term = log(arg);
    S += term;
    printf("k=%d term=%10.8f S=%10.8f\n", k, term, S);
    k++;
} while (fabs(term) >= epsilon && k <= max_iter);

printf("Результат S = %.10lf, число членов = %d\n", S, k-1);
